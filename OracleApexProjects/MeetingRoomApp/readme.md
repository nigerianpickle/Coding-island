# Enterprise Meeting Room Booking System (Oracle APEX)

## Overview
An enterprise web application built using Oracle APEX that allows employees to book meeting rooms while preventing scheduling conflicts through database-level business rules.

## Tech Stack
- Oracle APEX  
- Oracle SQL  
- PL/SQL  

## Features
- Meeting room management  
- Conflict-free room booking  
- Interactive reports and forms  
- Role-based access control  
- Dashboard for room utilization  

## Business Rules
- Prevents overlapping bookings using PL/SQL triggers  
- Enforces valid meeting time ranges  

## Setup
1. Run SQL scripts in `database/`
2. Import APEX application from `apex/`
3. Load sample data
4. Run application
